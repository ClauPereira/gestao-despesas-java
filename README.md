# 💰 Sistema de Gestão de Despesas

Aplicação de consola desenvolvida em Java para registo e gestão de despesas pessoais.

## 📋 Funcionalidades

- Adicionar despesas
- Listar despesas
- Calcular o total de despesas
- Pesquisar despesas por categoria
- Remover despesas
- Validação básica dos dados introduzidos

## 🛠️ Tecnologias

- Java 25
- IntelliJ IDEA
- GitHub

## 📚 Conceitos utilizados

- Programação Orientada a Objetos
- Classes e objetos
- Encapsulamento
- ArrayList
- Métodos
- Estruturas condicionais
- Estruturas de repetição
- Tratamento de exceções
- Scanner
- LocalDate

## ▶️ Como executar

1. Clonar ou descarregar o repositório.
2. Abrir o projeto numa IDE compatível com Java.
3. Executar a classe `Main`.
